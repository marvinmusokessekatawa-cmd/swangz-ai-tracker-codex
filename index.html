▸ Tool Registry Manager team-added tools

Tools the team has pinned to the registry. Built-in tools (Higgsfield, Suno, ElevenLabs, etc.) cannot be edited here. Renaming a team-added tool updates it everywhere; deleting it removes it from autocomplete (but does not touch any individual entries). Use the form below to add a new tool to the registry without waiting for a teammate to enter it.

+ Add new tool to registry

▸ Manage Submissions reassign · edit attribution

Fix mis-attributed entries — for example, if someone accidentally adopted an entry that wasn't theirs from the "Found N entries that may be yours" banner. Reassigning updates who the entry belongs to in My History on every device.

▸ Admin Access admin access

An admin gets the full Admin Dashboard — every department, the figures and the reports. Access is granted to a Swangz Avenue account only, and an admin cannot change this list themselves.

Admin access is granted and withdrawn by the system owner.
